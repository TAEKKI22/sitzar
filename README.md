# SITZAR

Official band website: **https://taekki22.github.io/sitzar/**

Pixel art, music links, and interactive TRACK 1 / TRACK 2 games.

This repository publishes the static site in `site.tar.gz` to GitHub Pages.
The archive contains only the files served by the website.

When a new `site.tar.gz` is committed to `main`, GitHub Actions redeploys it.
Local source edits are not published until a new build is uploaded.
